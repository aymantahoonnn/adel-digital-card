بطاقة التعريف الإلكترونية | Prof. Dr. Adel AbdelKhalek
====================================================

الملفات:
- index.html               الصفحة الرئيسية بالعربي والإنجليزي.
- profile.jpg              الصورة الأصلية الكاملة 720 × 720 بدون قص أو تغيير.
- adel-abdelkhalek.vcf     ملف حفظ بيانات جهة الاتصال.
- README_AR.txt            هذا الملف.

للمعاينة قبل النشر:
1- فك ضغط ملف ZIP بالكامل في مجلد واحد.
2- افتح index.html في Chrome أو Edge أو أي متصفح.
3- اضغط English / العربية للتبديل بين اللغتين.
4- اضغط على الصورة لرؤية الملف الأصلي بالحجم الكامل.
5- واتساب والبريد والاتصال ستفتح تطبيقاتها عند توفرها على الجهاز.
6- زر حفظ جهة الاتصال يفتح/ينزّل ملف vCard، والحفظ النهائي يحتاج موافقة صاحب الموبايل.

تعديل المعلومات:
- غيّر الأسماء/المسميات الظاهرة في index.html في قسم labels إن احتجت،
  وإذا تغيّر رقم الهاتف أو البريد الإلكتروني غيّر روابط الأزرار أيضًا.
- عدّل adel-abdelkhalek.vcf بنفس البيانات للحفظ الصحيح.
- لتغيير الصورة، استبدل profile.jpg بصورة أخرى بنفس الاسم؛ الصورة معروضة كاملة بدون قص.

النشر المجاني لاحقًا عبر GitHub Pages (بعد الموافقة على الشكل):
1- افتح حساب GitHub، ثم أنشئ مستودعًا عامًا مثل adel-card.
2- ارفع الملفات index.html و profile.jpg و adel-abdelkhalek.vcf في جذر المستودع.
3- افتح Settings > Pages > Build and deployment > Deploy from a branch.
4- اختر main و /(root) ثم Save.
5- بعد نجاح النشر، ستحصل على رابط حقيقي مثل https://USERNAME.github.io/adel-card/
   (هذا مجرد مثال، وليس رابط الصفحة الحالي).
6- بعد ذلك فقط أنشئ Static QR Code يشير للرابط الفعلي؛ لا نولّد QR برابط افتراضي.
7- لتحديث الصورة/البيانات لاحقًا ارفع الإصدارات الجديدة من الملفات بنفس الأسماء؛
   طالما عنوان الصفحة ثابت، لن تحتاج إعادة طباعة QR.
8- لإيقاف الصفحة مؤقتًا أو إعادة نشرها استخدم إعدادات GitHub Pages.

تنبيهات مهمة:
- الملفات الحالية للمعاينة المحلية وليست منشورة على الإنترنت بعد.
- QR ثابت لا تنتهي صلاحيته بذاته، لكن استمرار عمله يعتمد على استمرار رابط الاستضافة.
- GitHub Pages مجاني ضمن شروط الخدمة، ولا توجد خدمة مجانية مضمونة للأبد.
- ملف حفظ جهة الاتصال لا يحفظ البيانات تلقائيًا بدون موافقة الشخص.
- الموقع عام عند نشره، فلا تضع بيانات لا تريد إظهارها للآخرين.
